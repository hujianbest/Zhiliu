# 35: Agent 自动触发条件配置

**What to build:** 用户配置 Agent 在什么条件下自动分析新增的来源文档与笔记，使发现变得主动但始终可控。自动工作严格遵守后台预算，结果进入建议收件箱而不直接改动用户内容，用户可以随时全部关闭。

**Blocked by:** 21, 32

**Status:** ready-for-agent

**Starting failing test:** 配置一个触发条件并制造触发，断言自动运行发生、遵守后台预算、结果只进入建议收件箱而未改动任何用户内容。

**Demo acceptance:** 需要。自动工作的可控感与状态可见性需要人判断。

- [ ] 用户可以配置自动分析的触发条件，例如新增内容之后或按时间间隔
- [ ] 自动运行严格遵守后台 Token 与请求上限
- [ ] 用户可以一处关闭全部自动工作
- [ ] 自动运行的结果进入建议收件箱，不直接改动用户内容
- [ ] 自动运行的当前状态与最近一次运行时间对用户可见
