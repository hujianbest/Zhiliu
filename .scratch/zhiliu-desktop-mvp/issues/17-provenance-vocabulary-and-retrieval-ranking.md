# 17: 三值来源归属与检索排序

**What to build:** 系统里每一段文字都带一个三值来源归属标签：用户、来源、AI。这套词汇在全系统只有一份，从笔记字段到编辑器段落到对话段落都是同一套，不做任何映射转换。检索默认按这三值排序，让召回结果先反映用户自己的思考。本票只建立词汇与排序；AI 修订的生成与接受在票 27。

**Blocked by:** 08, 12

**Status:** done

**Starting failing test:** 建一条思想笔记与一条只含引文的摘录，两者含同一个词，检索该词，断言思想笔记的想法字段排在摘录之前，且两者的归属标签分别为用户与来源；再断言把摘录的归属手工改为用户的任何路径都不存在。

**Demo acceptance:** 不需要。词汇取值与排序结果都由断言覆盖，本票不引入用户需要做判断的界面。

- [x] 全系统使用同一套三值来源归属词汇：用户、来源、AI，不存在第二套平行词汇（ADR-0004）
- [x] 思想笔记的想法字段归属为用户，引文字段归属为来源
- [x] 检索默认排序为用户、来源、AI
- [x] 摘录以来源归属参与检索，排在思想笔记之后
- [x] 任务相关的重排序不会抹掉归属标签
- [x] 归属由内容的真实出处决定，不提供手工设置归属的入口
