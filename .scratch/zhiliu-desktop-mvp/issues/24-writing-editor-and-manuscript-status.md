# 24: 创作编辑器、稿件实体与定稿状态

**What to build:** 创作空间提供带实时预览的 Markdown 编辑器，用户可以手工新建并撰写一篇稿件，不依赖任何 AI 生成路径。稿件带种类与状态两个维度：种类为试写或正式，状态为草稿或定稿，合法组合只有试写+草稿、正式+草稿、正式+定稿三种，试写+定稿不存在（ADR-0003）。用户把一份正式稿从草稿定稿，也可以撤回定稿；定稿是一个有后果的动作而不是一个标签，因为只有定稿的正式稿进入检索语料（ADR-0011）。归属的视觉呈现与跳源在票 31。

**Blocked by:** 17

**Status:** ready-for-agent

**Starting failing test:** 手工新建一篇正式稿并写入一段只出现在其中的独特词句，断言实时预览反映编辑内容；在草稿状态下检索该词句断言不命中，把稿件定稿后再检索断言命中，撤回定稿后再检索断言重新不命中。

**Demo acceptance:** 需要。编辑与预览的手感、以及「定稿」这个动作的后果是否被用户理解，只能人判断。

- [ ] 创作空间提供带实时预览的 Markdown 编辑器
- [ ] 用户可以手工新建、撰写、保存一份稿件，全程不需要任何 AI 生成
- [ ] 稿件带种类与状态两个维度，合法组合只有试写+草稿、正式+草稿、正式+定稿三种
- [ ] 用户可以把正式稿从草稿定稿，也可以撤回定稿
- [ ] 只有种类为正式、状态为定稿的稿件进入检索语料（ADR-0011）
- [ ] 测试断言未定稿的正式草稿不被检索召回
- [ ] 稿件进入自动 Git 追踪（承接票 11 声明的追踪范围）
- [ ] 编辑器使用与笔记层同一套三值来源归属，不做任何映射转换（ADR-0004）
- [ ] AI 生成的措辞可以像普通 Markdown 一样自由编辑
- [ ] 全局 Agent 侧栏在创作空间同样可用
