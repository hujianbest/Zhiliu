# 07: 目录导航与阅读状态

**What to build:** 用户通过目录在长篇作品中高效移动，关闭应用后重新打开会回到上次阅读的位置。阅读状态只反映真实的本地阅读进度或用户的显式确认，模型对来源的摘要或分析永远不会代替用户把一份来源文档标记为已读——这条规则在本票定义，但它的断言在票 22，因为模型分析能力到那时才存在，在本票时点断言「分析不改变状态」会因为根本没有分析能力而恒真。

**Blocked by:** 05

**Status:** ready-for-agent

**Starting failing test:** 目录跳转到第三章，重启应用断言回到该位置且阅读状态为「在读」；读到末章断言状态变为「已读」，再撤销该标记断言回到「在读」。

**Demo acceptance:** 需要。目录与位置操作是否顺手需要人判断。

- [x] EPUB 目录可展示并跳转到对应章节
- [x] 关闭并重启应用后回到上次阅读位置
- [x] 阅读状态的取值是未读、在读、已读三值
- [x] 「在读」由真实本地阅读进度自动推出
- [x] 「已读」只能由真实读完或用户显式确认达成，用户也可以撤销该标记
- [x] 只有真实本地阅读进度与用户的显式动作能改变阅读状态；任何其他来源都不能，这条规则的断言由票 22 补充
- [x] 目录跳转与状态操作都有可见控件与快捷键
