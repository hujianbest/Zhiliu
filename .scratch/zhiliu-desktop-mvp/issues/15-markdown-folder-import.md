# 15: Markdown 文件夹导入

**What to build:** 用户选择一个已有的 Markdown 文件夹，内容被复制进知流知识库，从此参与检索与写作。原始位置的文件保持不变，知流不会悄悄改动另一个工具的仓库；导入之后原文件夹的后续修改也不再同步，这一点对用户明确可见。

**Blocked by:** 02, 12

**Status:** done

**Starting failing test:** 导入一个外部 Markdown 文件夹，断言内容可被全文与语义检索命中，且原文件夹在导入前后逐字节未变；再导入一个含文件名冲突与无法映射元数据的文件夹，断言生成的导入报告逐条列出被重命名的文件与未映射的字段。

**Demo acceptance:** 需要。「一次性复制、后续不同步」这件事有没有被用户真正读到，只能人判断。

- [x] 用户选择一个外部 Markdown 文件夹，内容被复制进知识库
- [x] 尽可能保留原有元数据，无法映射的部分写入导入报告而不静默丢弃
- [x] 文件名冲突有明确处理且不覆盖已有笔记，重命名结果写入导入报告
- [x] 导入报告是知识库中一份可被外部编辑器读取的产物，因此上述两条既有界面表达也有可断言的持久形式
- [x] 测试断言原始外部文件夹在导入前后完全未被修改
- [x] 导入内容参与全文与语义检索
- [x] 界面明确说明导入是一次性复制，原文件夹后续变更不同步
