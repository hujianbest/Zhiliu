# 32: 从采纳改稿学习风格

**What to build:** AI 草稿与用户最终稿之间被采纳的差异成为风格更新的依据，系统因此适应用户真实的选择而不是想象的偏好。每条更新提案都展示自己的证据，必须经用户确认才生效，一篇异常的文章不会静默重新定义用户的声音。

**Blocked by:** 28, 31

**Status:** ready-for-agent

- [ ] AI 草稿与用户最终稿之间被采纳的差异形成风格更新提案
- [ ] 每条提案展示其依据，即具体的差异或样本文章
- [ ] 测试断言未经用户确认的风格变更绝不生效
- [ ] 确认后的变更进入风格档案版本历史并可回滚
- [ ] 单篇异常文章不会静默改写用户的声音
