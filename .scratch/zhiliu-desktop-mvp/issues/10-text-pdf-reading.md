# 10: 文本型 PDF 导入与阅读

**What to build:** 用户导入本地的文本型 PDF，报告与图书作为来源文档进入书库，可以翻页阅读、使用可得的目录、恢复上次阅读页，并选中文本层的文字保存笔记。PDF 笔记的出处包含页码与页内坐标，可以跳回该位置核对。本版本不含 OCR，因此没有文本层的扫描件必须明确告知用户无法选中文字，而不是让人对着一页图片反复尝试。

**Blocked by:** 07, 08

**Status:** ready-for-agent

**Starting failing test:** 导入文本型 PDF 素材、选中文本层保存一条思想笔记，断言其出处含页码与页内坐标并可跳回该位置。

**Demo acceptance:** 需要。翻页手感与渲染清晰度需要人看。

- [x] 导入本地文本型 PDF，条目立即出现在书库
- [x] 页面可渲染、可翻页，有目录时可展示并跳转
- [x] 文本层可选中，并能通过既有的捕获流程保存笔记
- [x] PDF 笔记的出处包含页码与页内坐标，可跳回该位置
- [x] 重启后回到上次阅读页
- [x] 没有文本层的 PDF 仍可作为页面图片阅读，但界面明确说明本版本无法选中其文字（ADR-0009）
- [x] 索引进行时已可先阅读与捕获

## Comments

- 2026-08-30 主进程用 pdf.js 抽出文本层做成净化 HTML，走与 EPUB 相同的无脚本 iframe。出处为 `pdf:<page>:<start>:<end>:<x0>:<y0>:<x1>:<y1>`。无文本层时 chrome 提示无法选中。E2E：`e2e/pdf.spec.ts`。见 ADR-0024。
