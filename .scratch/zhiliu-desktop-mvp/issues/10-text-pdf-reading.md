# 10: 文本型 PDF 导入与阅读

**What to build:** 用户导入本地的文本型 PDF，报告与书籍进入书库，可以翻页阅读、使用可得的目录、恢复上次阅读页，并选中文本层的文字保存笔记。PDF 笔记的出处包含页码与页内坐标，可以跳回扫描位置核对。

**Blocked by:** 06, 07

**Status:** ready-for-agent

- [ ] 导入本地文本型 PDF，条目立即出现在书库
- [ ] 页面可渲染、可翻页，有目录时可展示并跳转
- [ ] 文本层可选中，并能通过既有的捕获流程保存笔记
- [ ] PDF 笔记的出处包含页码与页内坐标，可跳回该位置
- [ ] 重启后回到上次阅读页
- [ ] 索引进行时已可先阅读与捕获
