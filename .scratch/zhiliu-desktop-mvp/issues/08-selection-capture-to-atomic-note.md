# 08: 选中捕获为原子笔记

**What to build:** 阅读中选中一段文字后按快捷键，弹出轻量输入框写下当下的想法，回车即保存为一条思想笔记，整个过程不打断阅读。不写想法直接保存则得到一条摘录。每条笔记完整记录引文、来源身份、章节或页码与精确出处，之后可以跳回原文核对上下文。阅读时可以随时查看当前来源下的全部笔记。

**Blocked by:** 05

**Status:** ready-for-agent

**Starting failing test:** 选中一段文字、按快捷键、输入想法、回车，断言磁盘出现一条思想笔记，且能从它跳回精确出处。

**Demo acceptance:** 需要。捕获是否真的不打断阅读，只有人能感觉到。

- [ ] 选中文本、按快捷键、输入想法、回车保存的完整路径不离开阅读界面
- [ ] 思想笔记包含引文、用户想法、来源身份、章节或页码、精确出处
- [ ] 不写想法直接保存得到一条摘录，它不计入写作就绪
- [ ] 从笔记可以跳回来源的精确出处并看到上下文
- [ ] 阅读界面可以列出当前来源的全部笔记，并区分摘录与思想笔记
- [ ] 捕获动作同时提供可见控件，不只有隐藏快捷键
- [ ] 重启应用后笔记与其出处仍然可用
