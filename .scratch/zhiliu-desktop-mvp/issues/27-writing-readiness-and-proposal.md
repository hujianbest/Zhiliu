# 27: 写作就绪规则与提案审阅

**What to build:** 当某个主题积累到可能支撑一篇文章时，Agent 给出提案而不是直接动笔：提案展示论点、支撑的用户思想、书籍与网页证据、AI 推演，以及被识别出的缺口与薄弱推理，让用户在生成之前就能检查这套理由。用户确认或修改论点、逐条纳入或排除证据。只有「一个用户确认的论点 + 至少三条用户提供或明确接受的思想」才算写作就绪；不达标的主题保持为提案，不被表述为用户的声音。

**Blocked by:** 22, 26

**Status:** ready-for-agent

- [ ] 提案展示论点、支撑用户思想、来源证据、AI 推演与识别出的缺口
- [ ] 用户可以确认或修改论点
- [ ] 用户可以逐条纳入或排除提案中的证据
- [ ] 测试断言不满足「一个确认论点 + 至少三条用户思想」时无法进入正式草稿
- [ ] 缺乏个人思想支撑的主题保持为提案，不被表述为用户的声音
- [ ] 缺失证据与薄弱推理在起草之前被明确指出
