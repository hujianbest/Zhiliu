# 34: 文章导出

**What to build:** 完稿后用户导出去掉编辑标色与编辑期标签的干净 Markdown，或复制为纯文本与富文本以便粘贴到简单编辑器或常见发布平台。默认带轻量脚注与来源清单以保持可信，引用密度可以编辑甚至整体关闭，以适配不同发表语境。

**Blocked by:** 31

**Status:** ready-for-agent

**Starting failing test:** 导出一篇含三种来源归属的稿件，断言输出的 Markdown 不含任何标色与编辑期标签，且脚注与来源清单可被关闭。

**Demo acceptance:** 需要。富文本粘贴到真实发布编辑器里的效果只能人验。

- [ ] 导出的 Markdown 不含编辑标色与编辑期标签
- [ ] 可以复制为纯文本
- [ ] 可以复制为富文本，并在常见发布编辑器中保留基本格式
- [ ] 默认生成轻量脚注与来源清单
- [ ] 引用可编辑，也可整体关闭
- [ ] 测试断言 Markdown、纯文本与富文本三种导出形态都不含 API Key 或任何凭据（承接票 03 无法断言的导出通道，导出物是唯一会被用户主动发到外部的产物）
- [ ] 不提供 DOCX 与 PDF 文章导出
