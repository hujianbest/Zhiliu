# 25: 默认提示词与用户覆盖

**What to build:** 内置的默认提示词是稳定的产品资产，新用户无需任何配置即可获得可用结果。高级用户可以创建覆盖并随时恢复出厂默认，因此提示词实验不会把首次使用变得脆弱，也不需要修改源码。

**Blocked by:** 11, 18

**Status:** ready-for-agent

**Starting failing test:** 覆盖一条提示词后断言生成留痕中的提示词版本反映覆盖，恢复默认后断言其反映默认。

**Demo acceptance:** 不需要。行为完全由断言覆盖。

- [ ] 内置默认提示词稳定可用，新用户无需任何配置
- [ ] 高级用户可以创建覆盖，无需修改源码
- [ ] 用户可以把被覆盖的提示词恢复为出厂默认
- [ ] 提示词覆盖进入自动 Git 追踪（承接票 11 声明的追踪范围）
