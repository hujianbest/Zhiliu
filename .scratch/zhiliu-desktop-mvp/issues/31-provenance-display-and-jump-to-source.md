# 31: 稿件的来源归属呈现与跳源

**What to build:** 稿件里的每一段文字都带着与笔记层完全相同的三值来源归属，用固定颜色区分，同时带文字或图形标签，因此色觉障碍与纯键盘用户也能分辨。从任一段落可以打开背后的笔记或来源文档查看上下文并修正。AI 措辞被编辑之后归属依然可追溯。本票从票 24 拆出：编辑器与稿件状态是一层，归属的呈现与跳源是另一层，合在一起会让一张票同时引入编辑器、实时预览、颜色系统、非颜色标签与跳源五件事。

**Blocked by:** 24

**Status:** done

**Starting failing test:** 打开一篇含三种来源归属的稿件，断言每种归属同时具备颜色与非颜色标签、且在剥离全部颜色信息后三者仍可区分；从一个来源归属段落跳转，断言落在对应笔记或来源文档的精确出处；编辑一段 AI 文字后断言其归属仍标为 AI 且可追溯到原始生成。

**Demo acceptance:** 需要。三种颜色在真实排版下是否舒适且可分辨，只能人看。

- [x] 三种归属用固定颜色区分，并同时带文字或图形标签
- [x] 归属区分在不感知颜色的情况下依然可识别，测试以剥离颜色的形式断言
- [x] 从段落可以打开背后的笔记或来源文档并查看上下文
- [x] 编辑之后归属依然可追溯
- [x] AI 修订被记录，不覆盖已被采纳的人类文字
- [x] 编辑期的标色与标签是呈现层产物，不写入稿件 Markdown 正文，因此导出无需清洗正文即可干净（票 34 断言导出侧）
