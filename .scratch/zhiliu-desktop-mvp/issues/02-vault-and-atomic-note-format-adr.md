# 02: 知识库创建与原子笔记格式 ADR

**What to build:** 首次运行时用户选择一个本地目录作为知流知识库，应用在其中建立可读的结构；重启后自动重新打开同一知识库。知识以带 Frontmatter 的原子 Markdown 文件保存，每条都有不依赖文件名与路径的稳定标识，因此用户在外部重命名文件或重组目录后，来源链接与笔记关系依然有效。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 记录知识库结构、Frontmatter 字段与稳定标识方案的 ADR，并说明哪些产物属于可重建的派生缓存
- [ ] 首次运行引导用户选择知识库位置并完成创建，重启后无需再次选择
- [ ] 原子笔记包含稳定标识、来源引用、引文、用户思想、创建与更新时间、作者归属与关系元数据
- [ ] 知识库中的 Markdown 可被外部文本编辑器直接打开阅读
- [ ] 在应用外重命名笔记文件并移动其所在目录后，应用内的来源链接与笔记关系仍然可达
- [ ] 用户可以手工把整个知识库目录复制到另一台机器并在那里打开，内容与关系完整
