# 02: 知识库创建与原子笔记格式 ADR

**What to build:** 首次运行时用户选择一个本地目录作为知流知识库，应用在其中建立可读的结构；重启后自动重新打开同一知识库。知识以带 Frontmatter 的原子 Markdown 文件保存，每条都有不依赖文件名与路径的稳定标识，因此用户在外部重命名文件或重组目录后，来源链接与笔记关系依然有效。原子笔记只有两种形态：只含引文的摘录，以及引文加用户想法的思想笔记。

**Blocked by:** 01

**Status:** ready-for-agent

**Starting failing test:** 首次运行创建知识库，断言磁盘上出现可被外部文本编辑器读取的结构；重启应用断言无需再次选择即打开同一知识库。

**Demo acceptance:** 需要。首次运行引导是否让人明白自己在选什么，只能人判断。

- [ ] 记录知识库结构、Frontmatter 字段与稳定标识方案的 ADR，并说明哪些产物属于可重建的派生缓存
- [ ] Frontmatter 字段名使用英文并与 `CONTEXT.md` 的术语一致，用户可见文案使用中文
- [ ] 首次运行引导用户选择知识库位置并完成创建，重启后无需再次选择
- [ ] 原子笔记包含稳定标识、来源引用、引文、用户想法、创建与更新时间、来源归属与关系元数据
- [ ] 摘录与思想笔记是同一种文件的两种形态，区别只在于用户想法字段是否为空
- [ ] 知识库中的 Markdown 可被外部文本编辑器直接打开阅读
- [ ] 在应用外重命名笔记文件并移动其所在目录后，应用内的来源链接与笔记关系仍然可达
- [ ] 用户可以手工把整个知识库目录复制到另一台机器并在那里打开，知识内容与关系都完整（本票时点知识库内还没有来源文件，来源文件随目录一并搬迁的断言由票 04 补充）
