# 25: 对话历史持久化与提炼为笔记

**What to build:** 有价值的探索不会丢失：对话历史被保存下来随时可查。但保存的对话默认不参与后续检索，模型输出因此不会递归污染知识库；只有用户显式提炼成原子笔记的段落才会进入知识检索。

**Blocked by:** 24

**Status:** ready-for-agent

- [ ] 对话历史被保存，重启后可继续查看
- [ ] 测试断言保存的对话默认不参与后续检索
- [ ] 用户可以选中对话中的段落并显式提炼为一条原子笔记
- [ ] 提炼出的笔记如实记录作者归属：源自 AI 输出且经用户审阅
- [ ] 只有被提炼的内容参与后续知识检索
