# 30: 对话历史持久化与提炼为笔记

**What to build:** 有价值的探索不会丢失：对话历史被保存下来随时可查。但保存的对话默认不参与后续检索，模型输出因此不会递归污染知识库；只有用户显式提炼成原子笔记的段落才会进入知识检索。

**Blocked by:** 17, 23

**Status:** ready-for-agent

**Starting failing test:** 保存一段对话后检索其中的独特词句，断言检索不命中；把该段落提炼为思想笔记后再检索，断言命中。

**Demo acceptance:** 需要。提炼流程的顺畅度需要人判断。

- [ ] 对话历史被保存，重启后可继续查看
- [ ] 测试断言保存的对话默认不参与后续检索
- [ ] 用户可以选中对话中的段落并显式提炼为一条原子笔记
- [ ] 提炼出的笔记如实记录来源归属：源自模型输出的文字归属为 AI，用户在提炼时补写的想法归属为用户（ADR-0004）
- [ ] 只有被提炼的内容参与后续知识检索
