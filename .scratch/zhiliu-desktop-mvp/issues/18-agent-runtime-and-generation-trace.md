# 18: Agent 运行时与生成留痕

**What to build:** 用户可以随时手动触发一次 Agent 分析而不必等待自动排期。Agent 用本地 Embedding 选出候选材料，把与任务相关的摘录交给配置的模型完成更高层的推理，运行状态与结果对用户可见。每次生成都在本地留下可查的记录，足以复现与审查，且不含任何凭据。

**Blocked by:** 03, 09

**Status:** ready-for-agent

- [ ] 记录 Agent 执行模型 ADR：触发方式、任务排队、本地召回与云端推理的分工、失败与重试策略
- [ ] 用户可以手动触发一次分析，运行状态与结果可见
- [ ] 模型访问统一走 OpenAI 兼容契约，并有针对受控服务的网关合约测试
- [ ] 每次生成记录任务类型、模型身份、提示词版本、来源标识、时间戳、用量与结果
- [ ] 测试断言生成记录中不含 API Key 或任何凭据
- [ ] 出站请求只包含为可见任务选择的摘录，而非整库上传
- [ ] 每个出站请求都可归因到一个用户可见的任务
