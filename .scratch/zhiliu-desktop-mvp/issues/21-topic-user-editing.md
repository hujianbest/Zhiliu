# 21: 主题的用户编辑与回滚

**What to build:** 用户重命名、合并、拆分、隐藏、固定主题，让组织方式反映自己的理解。被固定的主题不会被后续自动聚类替换，Agent 重跑不会摧毁用户刻意建立的结构。任何一次 Agent 组织操作都能被确定性地整体回滚。

**Blocked by:** 20

**Status:** ready-for-agent

- [ ] 用户可以重命名、合并、拆分、隐藏、固定主题
- [ ] 被固定的主题不会被后续自动聚类替换或重组
- [ ] 用户编辑后的主题结构在 Agent 重跑之后保持
- [ ] 一次 Agent 组织操作可被确定性回滚，回滚后主题结构与文件状态一致
- [ ] 所有操作都有可见控件与键盘路径
