# 42: 从采纳改稿学习风格

**What to build:** AI 草稿与用户最终稿之间被采纳的差异成为风格更新的依据，系统因此适应用户真实的选择而不是想象的偏好。每条更新提案都展示自己的证据，必须经用户确认才生效，一篇异常的文章不会静默重新定义用户的声音。

**Blocked by:** 36, 39

**Status:** done

**Starting failing test:** 制造一份 AI 草稿与用户最终稿的差异，断言产生带证据的风格更新提案，且在用户确认之前风格档案逐字节未变。

**Demo acceptance:** 需要。更新提案的说服力需要人判断。

- [x] AI 草稿与用户最终稿之间被采纳的差异形成风格更新提案
- [x] 每条提案展示其依据，即具体的差异或样本文章
- [x] 测试断言未经用户确认的风格变更绝不生效
- [x] 确认后的变更进入风格档案版本历史并可回滚
- [x] 单篇异常文章不会静默改写用户的声音（ADR-0012）
- [x] 证据已被删除的更新提案被撤回，而不是在证据缺失的情况下仍可确认（ADR-0012）
- [x] 学习输入为状态已定稿的正式稿与其对应的 AI 草稿之间的差异，未定稿的草稿不参与
