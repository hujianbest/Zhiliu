# 24: 知识库对话与证据边界标注

**What to build:** 用户在全局 Agent 侧栏中跨书籍、文章、笔记与合格草稿提问，对话式地探索积累的知识。回答的每个段落都标明它是知识库证据还是模型补充，证据段落可以跳转到精确来源去核对。模型在有帮助时可以使用通用知识，但流畅的表述不会被误认为库内已有的依据。

**Blocked by:** 09, 18

**Status:** ready-for-agent

- [ ] 用户可以跨书籍、文章、笔记与合格草稿提问并得到回答
- [ ] 回答的每个段落标注为知识库证据或模型补充
- [ ] 证据段落可链接跳转到精确来源
- [ ] 缺乏库内依据的论断被标为模型补充，不伪装为证据
- [ ] 模型在有帮助时可以使用通用知识，答案不被人为限制在库内
- [ ] 断网或模型不可用时对话明确失败，其他功能不受影响
