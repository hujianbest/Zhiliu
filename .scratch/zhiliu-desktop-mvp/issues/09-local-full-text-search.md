# 09: 本地全文检索

**What to build:** 用户用一个检索入口在来源文档与笔记之间查找已知的词句，中英文都能命中，结果可以跳到出处。检索完全在本地完成，断网可用。中文分词走 SQLite 内置的 trigram，两字词由应用层降级为 `LIKE` 匹配——在本项目的语料规模上这点代价可以接受，而它换掉的是一套需要三平台交叉编译的分词扩展。检索语料的完整资格由 ADR-0011 规定：本票时点只有来源文档与笔记存在，稿件进入语料的断言由票 24 承接。

**Blocked by:** 08

**Status:** ready-for-agent

**Starting failing test:** 检索一个只出现在笔记里的中文词和一个只出现在来源文档正文里的英文词，断言各自命中并能跳到出处；再检索一个两字中文词，断言同样命中；再在一份来源文档尚未索引完成时检索，断言结果中明确标注该来源仍在索引。

**Demo acceptance:** 需要。结果的可读性与相关性排序需要人判断。

- [x] 一个检索入口跨来源文档与笔记检索
- [x] 全文检索基于 SQLite FTS5，中文使用内置 trigram 分词器
- [x] 少于三个字符的中文词由应用层降级为 `LIKE` 匹配，不引入任何编译的分词扩展（ADR-0008）
- [x] 拉丁文查询与含中日韩字符的查询分别路由到合适的索引，结果合并打分
- [x] 结果显示来源类型并可跳转到精确出处
- [x] 导入与编辑后新内容出现在检索结果中
- [x] 检索在断网时可用
- [x] 结果中标注仍在索引的来源，避免把部分结果误认为完整结果；这是索引状态在检索侧的唯一断言处，票 12 不重复
