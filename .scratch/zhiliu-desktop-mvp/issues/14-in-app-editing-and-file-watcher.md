# 14: 应用内 Markdown 编辑与外部编辑监听

**What to build:** 用户既可以在知流内直接编辑笔记，也可以用 Obsidian 或 VS Code 编辑同一批文件；在应用外做的修改无需重启就会出现在知流里，索引增量刷新。外部写入的非法或不完整产物被校验并给出可读提示，而不是破坏索引。

**Blocked by:** 07, 09

**Status:** ready-for-agent

- [ ] 应用内可以编辑笔记 Markdown 并保存
- [ ] 在应用外修改知识库文件后，应用无需重启即反映变化并增量刷新索引
- [ ] 在应用外新增或删除知识库文件同样被感知
- [ ] 外部写入的非法或不完整产物被校验并给出可读提示，索引不被破坏
- [ ] 端到端测试在应用运行时用外部方式修改文件并断言刷新
