# 12: Markdown 文件夹导入

**What to build:** 用户选择一个已有的 Markdown 文件夹，内容被复制进知流知识库，从此参与检索与写作。原始位置的文件保持不变，知流不会悄悄改动另一个工具的仓库；导入之后原文件夹的后续修改也不再同步，这一点对用户明确可见。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 用户选择一个外部 Markdown 文件夹，内容被复制进知识库
- [ ] 尽可能保留原有元数据，无法映射的部分可见而不静默丢弃
- [ ] 文件名冲突有明确处理且不覆盖已有笔记
- [ ] 测试断言原始外部文件夹在导入前后完全未被修改
- [ ] 导入内容参与全文与语义检索
- [ ] 界面明确说明导入是一次性复制，原文件夹后续变更不同步
