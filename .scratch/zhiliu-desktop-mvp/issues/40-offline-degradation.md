# 40: 离线降级与 AI 失败可恢复

**What to build:** 没有网络或模型不可用时，阅读、笔记捕获与编辑、本地检索、外部编辑同步、历史时间线与手工写作全部继续可用，应用优雅降级而不是停摆。AI 动作以清晰可恢复的错误结束，不静默卡住也不丢失用户已输入的内容；后台 Agent 在模型不可用时暂停而不是反复重试耗尽预算。

**Blocked by:** 16, 23, 36

**Status:** ready-for-agent

**Starting failing test:** 在禁用网络的条件下走完阅读、捕获、本地检索、外部编辑同步、历史时间线与手工写作，断言全部可用，且 AI 动作以可恢复的错误结束并未丢失已输入内容。

**Demo acceptance:** 需要。失败提示是否让人明白发生了什么，只能人判断。

- [ ] 断网时阅读、笔记捕获与编辑、本地全文与语义检索、外部编辑同步、历史时间线、手工写作全部继续可用
- [ ] 模型不可用时 AI 动作以清晰可恢复的错误结束，不丢失用户已输入的内容
- [ ] 后台 Agent 在模型不可用时暂停，不反复重试耗尽预算
- [ ] 端到端测试在禁用网络的条件下运行完整离线场景
- [ ] 网络恢复后无需重启即可继续使用 AI 功能
