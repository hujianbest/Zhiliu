# 19: Agent 预算与用量报告

**What to build:** 用户为后台工作设置日与月的 Token 上限和请求数上限，并能看到区分交互式与后台的累计用量，因此即使不清楚服务商定价也能理解活动量。后台预算耗尽时主动工作干净暂停，不影响用户主动发起的请求，除非用户自己配置了共享硬上限。

**Blocked by:** 18

**Status:** ready-for-agent

- [ ] 用户可配置后台工作的日与月 Token 上限及请求数上限
- [ ] 用量报告区分交互式与后台调用并展示累计值
- [ ] 后台预算耗尽时主动工作干净暂停，暂停状态对用户可见
- [ ] 暂停不阻塞用户主动发起的请求，除非用户配置了共享硬上限
- [ ] 新的一天或新的一月到来后后台工作可继续
- [ ] 在不知道服务商定价的情况下，请求数与累计用量仍能说明活动量
