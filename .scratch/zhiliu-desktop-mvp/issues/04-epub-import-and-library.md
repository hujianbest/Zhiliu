# 04: EPUB 导入与书库列表

**What to build:** 用户导入本机合法持有的无 DRM EPUB 文件，文件被复制进知识库目录，来源文档在可渲染之后立即出现在书库列表中，索引在后台继续进行而不阻塞浏览。书库是用户查看与恢复全部来源文档的入口。

**Blocked by:** 02

**Status:** ready-for-agent

**Starting failing test:** 导入 EPUB 素材后断言书库列表出现该来源文档的标题，且原件已被复制进知识库的来源目录；随后把整个知识库目录复制到另一个路径并打开，断言来源文件与其笔记关系都完整（承接票 02 未能断言的部分）。

**Demo acceptance:** 需要。书库列表的信息密度与可浏览性需要人看。

- [ ] 用户可以选择一个或多个本地 EPUB 文件导入
- [ ] 导入时把原件复制进知识库目录，原始位置的文件不被改动（ADR-0001）
- [ ] 来源文件与派生提取产物确实存在于知识库目录内，但被 Git 排除
- [ ] 导入的来源文档立即出现在书库列表中，展示标题与可得的作者信息
- [ ] 书库列表统一展示全部来源文档，并显示每个来源当前的索引状态（索引状态的取值与其变化断言由票 12 补充，本票只断言该位置存在且反映导入完成度）
- [ ] 知识库目录被整体复制到别处后，来源文件与笔记关系都完整
- [ ] 导入损坏或不支持的 EPUB 时给出明确失败原因，不留下半成品条目
- [ ] 端到端测试使用真实的小体积 EPUB 素材
