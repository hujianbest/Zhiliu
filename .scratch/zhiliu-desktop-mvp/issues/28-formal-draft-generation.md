# 28: 正式草稿生成

**What to build:** 通过就绪检查的提案生成正式草稿并进入创作编辑器，草稿只使用用户确认纳入的证据，并按来源痕迹规则标注用户原话、书中内容与 AI 推演。正式文章与 AI 试写稿在界面上有明确区分。生成失败时提案与已确认的选择不会丢失。

- [ ] 草稿按来源痕迹规则标注用户原话、书中内容与 AI 推演
- [ ] 草稿只使用用户确认纳入的证据
- [ ] 正式文章与 AI 试写稿在界面上有明确区分
- [ ] 生成过程留下完整的生成记录
