# 06: 目录导航与阅读位置恢复

**What to build:** 用户通过目录在长篇作品中高效移动，关闭应用后重新打开会回到上次阅读的位置。阅读状态只反映真实的本地阅读进度或用户的显式确认，模型对来源的摘要或分析永远不会代替用户把一本书标记为已读。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] EPUB 目录可展示并跳转到对应章节
- [ ] 关闭并重启应用后回到上次阅读位置
- [ ] 阅读进度只由真实本地阅读行为或用户显式操作更新
- [ ] 用户可以显式把一本书标记为已读或撤销该标记
- [ ] 测试断言模型对来源的分析或摘要不改变其阅读状态
- [ ] 目录跳转与位置操作都有可见控件与快捷键
