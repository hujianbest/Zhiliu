# 22: 建议收件箱与双队列

**What to build:** 主动发现的结果汇聚到应用内的建议收件箱，而不是打扰式的系统通知。收件箱分为「你的思想线索」与「从书库发现」两个队列：前者只基于用户撰写的笔记，后者可以分析全部导入内容包括未读材料。语料里的观点因此不会被表述为用户自己的信念。

**Blocked by:** 21

**Status:** ready-for-agent

- [ ] 收件箱分为「你的思想线索」与「从书库发现」两个队列
- [ ] 思想线索队列只基于用户撰写的笔记
- [ ] 书库发现队列可分析全部导入内容，包括未读材料
- [ ] 每条建议展示其证据并可跳转到来源
- [ ] 测试断言书库语料的观点不被表述为用户自己的信念
- [ ] 建议只在应用内呈现，不使用系统级打扰通知
- [ ] 用户可以采纳或忽略建议，状态持久保存
