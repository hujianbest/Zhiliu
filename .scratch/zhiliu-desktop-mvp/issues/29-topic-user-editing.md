# 29: 主题的用户编辑与回滚

**What to build:** 用户重命名、合并、拆分、隐藏、固定主题，让组织方式反映自己的理解。被固定的主题不会被后续自动聚类替换，Agent 重跑不会摧毁用户刻意建立的结构。固定保护的是分组结构，不是主题来源：证据减少到三条思想笔记以下时，来源仍会自动降为书库发现，已生成的试写稿保留但不再生成新的。任何一次 Agent 组织操作都能被确定性地整体回滚。

**Blocked by:** 22

**Status:** ready-for-agent

**Starting failing test:** 固定一个主题后重跑聚类，断言结构未变；再删掉该主题的笔记使其掉到三条以下，断言来源自动降为书库发现而固定关系仍在；反向补回一条思想笔记，断言来源自动升回思想线索（ADR-0002 的双向推导）。

**Demo acceptance:** 需要。降级是否让用户理解发生了什么，只能人判断。

- [ ] 用户可以重命名、合并、拆分、隐藏、固定主题
- [ ] 被固定的主题不会被后续自动聚类替换或重组
- [ ] 固定不冻结主题来源，来源始终随证据变化而双向自动推导（ADR-0002）
- [ ] 书库发现主题在用户为它写下第三条思想笔记后自动成为思想线索，界面上呈现这条出路，而不是提供重新分类的入口（ADR-0002）
- [ ] 思想线索因证据减少而降为书库发现时，已生成的试写稿保留，但不再自动生成新的
- [ ] 用户编辑后的主题结构在 Agent 重跑之后保持
- [ ] 一次 Agent 组织操作可被确定性回滚，回滚后主题结构与文件状态一致
- [ ] 所有操作都有可见控件与键盘路径
