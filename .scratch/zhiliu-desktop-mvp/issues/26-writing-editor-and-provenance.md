# 26: 创作编辑器与来源痕迹呈现

**What to build:** 创作空间提供带实时预览的 Markdown 编辑器。用户原话、书中内容与 AI 推演用固定颜色区分，同时带文字或图形标签，因此色觉障碍与纯键盘用户也能分辨来源。从任一生成段落可以打开背后的笔记或来源查看上下文并修正。AI 措辞可以像普通 Markdown 一样自由编辑，编辑之后来源痕迹依然可追溯。

**Blocked by:** 16

**Status:** ready-for-agent

- [ ] 创作空间提供带实时预览的 Markdown 编辑器
- [ ] 用户原话、书中内容、AI 推演用固定颜色区分，并同时带文字或图形标签
- [ ] 来源区分不依赖颜色也能被识别
- [ ] 从生成的段落可以打开背后的笔记或来源并查看上下文
- [ ] AI 生成的措辞可以像普通 Markdown 一样自由编辑
- [ ] 编辑之后来源痕迹依然可追溯
- [ ] AI 修订被记录，不覆盖已被采纳的人类文字
- [ ] 全局 Agent 侧栏在创作空间同样可用
