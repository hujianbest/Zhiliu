# 39: 写作风格档案

**What to build:** 用户指定自己以往的文章作为风格样本，Agent 由此产出一份可读的风格档案，描述学到的写作倾向。档案是可检视的一等产物而非隐藏状态：用户可以手工修改、查看版本历史、回滚到之前版本、也可以完全重置已学习的风格。

**Blocked by:** 24, 36

**Status:** ready-for-agent

**Starting failing test:** 指定两篇旧文章作为风格样本，断言产生可读的风格档案，且手工编辑、回滚到上一版本、完全重置三个动作都生效。

**Demo acceptance:** 需要。风格档案是否真的可读、描述是否贴切，只能人判断。

- [ ] 用户可以指定自己以往的文章作为风格样本
- [ ] 生成的风格档案是可读的描述性产物，而非隐藏的内部状态
- [ ] 用户可以手工编辑风格档案
- [ ] 风格档案有版本历史，可回滚到之前版本
- [ ] 用户可以完全重置已学习的风格
- [ ] 风格档案参与草稿生成，且其影响对用户可见（票 36 已提供生成路径，因此本条可被真正断言）
- [ ] Agent 绝不直接写入风格档案，任何变更都必须经用户确认（ADR-0012）
