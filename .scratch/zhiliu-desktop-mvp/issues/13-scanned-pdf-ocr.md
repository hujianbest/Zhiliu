# 13: 扫描版 PDF 本地 OCR

**What to build:** 导入扫描版 PDF 时在本机完成中英文识别，用户能看到进度与错误并可以取消。识别后的文本可以选中并用于捕获笔记，出处保留页坐标可跳回扫描原页。全过程不上传任何页面。

排期说明：本票是 spec 明确指定的第一个可砍范围。若 3–6 个月的开发周期受到威胁，应先推迟本票，而不是削减 EPUB 阅读、文本 PDF、知识库对话或主动主题发现。

**Blocked by:** 10

**Status:** ready-for-agent

- [ ] 记录 OCR 运行时选型 ADR，并说明其对安装包体积与 CPU 占用的影响
- [ ] 中文与英文的固定扫描页素材上产出可选中的识别文本
- [ ] OCR 进度可见，失败原因明确，用户可取消且取消后状态一致
- [ ] 由 OCR 文本形成的笔记出处含页坐标并可跳回
- [ ] 测试断言 OCR 过程无任何出站网络请求
- [ ] OCR 缓存产物不进入 Git 历史
