# 20: 主题自动聚类与证据展示

**What to build:** Agent 把来自不同书籍的笔记聚成命名主题，让反复出现的想法跨来源变得可见。每个主题都展示自己的依据：源自用户思想的主题展示支撑它的笔记，源自书库的主题展示书籍证据，用户因此可以判断这个模式是否真实存在。分析未读内容不会把书标记为已读。一次 Agent 组织操作成组提交，可以在历史时间线中作为一个操作查看。

**Blocked by:** 17, 18

**Status:** ready-for-agent

- [ ] Agent 可以把跨来源的笔记聚成主题并给出可读的名称
- [ ] 主题是持久化的用户所有实体，重启后仍然存在
- [ ] 用户思想主题展示支撑笔记，书库发现主题展示书籍证据
- [ ] 证据条目可跳转到笔记或来源的精确位置
- [ ] 分析未读来源不改变其阅读状态
- [ ] 一次 Agent 组织操作成组提交，在历史时间线中呈现为一个操作
