# 29: 自动 AI 试写稿

**What to build:** 用户打开应用就能看到一篇已经写出来的东西：符合就绪规则的用户思想主题会在后台预算内自动生成完整试写稿，并显著标注为「AI 试写」的推测性产物，在用户确认论点与材料之前与正式文章保持分离。仅来自书库发现的主题只产生提案，不自动生成完整草稿，主动生成因此始终贴着用户自己的思考。

**Blocked by:** 19, 28

**Status:** ready-for-agent

- [ ] 只有满足写作就绪规则的用户思想主题会自动生成完整试写稿
- [ ] 仅来自书库发现的主题只产生提案，不自动生成完整草稿
- [ ] 自动试写稿显著标注为「AI 试写」的推测性产物
- [ ] 自动试写稿在用户确认论点与材料之前与正式文章保持分离
- [ ] 自动生成受后台预算约束，预算耗尽时不再生成
- [ ] 用户打开应用即可看到已生成的试写稿
