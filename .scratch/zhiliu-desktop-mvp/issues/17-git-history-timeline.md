# 17: 自动 Git 提交与应用内历史时间线

**What to build:** 知识库的变化自动形成可回滚的历史，用户在应用内看到的是一条友好的操作时间线，不需要任何命令行知识即可回到之前的状态。追踪范围限于 Markdown 知识与轻量元数据，书籍二进制、OCR 产物、索引与缓存被忽略，历史因此保持可用。高级用户仍可用外部 Git 工具查看同一仓库。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 记录 Git 集成方式与追踪边界的 ADR
- [ ] Markdown 知识、主题、风格档案、文章、提示词覆盖与轻量关系元数据被自动提交
- [ ] 书籍二进制、OCR 产物、本地模型、索引、日志与缓存被忽略
- [ ] 应用内历史时间线以友好语言展示操作，用户可在界面内回滚到之前状态
- [ ] 回滚后应用内视图、索引与文件状态一致
- [ ] 高级用户可以用外部 Git 工具打开同一仓库查看提交
- [ ] 不提供分支管理、交互式 rebase、远端托管等完整 Git 客户端功能
