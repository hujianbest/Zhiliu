# 13: 网页 URL 导入

**What to build:** 用户粘贴一个公开文章的 URL，应用在本地生成净化后的可读正文快照并存入书库，尽可能保留标题、作者、来源 URL 与抓取时间以便日后引用可追溯。需要登录、有付费墙或无法提取的页面明确失败，绝不假装导入成功。

**Blocked by:** 05, 08, 09

**Status:** done

**Starting failing test:** 导入一个受控公开 HTML 素材的 URL，断言正文与元数据被提取、脚本被净化；再导入登录墙素材，断言明确失败且不留条目。

**Demo acceptance:** 需要。正文提取的可读性需要人判断。

- [x] 粘贴公开文章 URL 后在本地生成可读的正文快照并进入书库
- [x] 尽可能保留标题、作者、来源 URL 与抓取时间
- [x] 活动脚本与不安全内容被净化，测试以受控 HTML 素材断言
- [x] 需要登录、付费墙或无法提取的页面给出明确失败信息，不留下不完整条目
- [x] 不复用浏览器 Cookie、不绕过付费墙、不驱动已登录浏览器
- [x] 导入的文章可被检索并可作为笔记来源
