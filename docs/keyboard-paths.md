# 核心流程键盘路径上限

这些上限写进 `e2e/accessibility.spec.ts`。超出即失败。不得用基线放宽。

| 流程 | 上限（键次） | 路径 |
| --- | --- | --- |
| 打开检索 | 1 | Ctrl+K |
| 打开设置 | 1 | Ctrl+, |
| 打开创作 | 1 | Ctrl+3 |
| 导入阅读捕获 | 8 | 导入 → 打开书籍 → 选中 → Ctrl+M 记下 |
| 导出当前稿件 | 12 | 创作 → 选稿 → 导出 Markdown |
| 完整 Tab 一圈 | 80 | 焦点不得落回 `body` |

每个带快捷键的动作都有对应可见控件：检索、设置、记下这段、目录、上一章、下一章、标记已读。
